# Task Summary - DevOps Internship Task 4

This task focused on learning and applying **shell scripting basics** using Bash on an **AWS Ubuntu EC2 instance**.

During this task, I created multiple shell scripts that demonstrate:
- Use of **shebang** to specify the script interpreter
- Implementation of **variables, loops, and conditional statements**
- Automation of **system information retrieval**
- Automation of **temporary file and log cleanup**

I also documented the commands used and organized the project structure in a GitHub repository for submission.

By completing this task, I gained hands-on experience in:

- Structuring and maintaining a GitHub repository for DevOps projects
